# KosenNIGHT 改善版

## 起動

KosenNIGHTフォルダー全体をPC内へコピーし、直下の `KOSENFIGHT_Distribution.exe` を開きます。EXEだけを移さず、Engineフォルダーとゲームデータを同じ配置で保ってください。UEエディターは不要です。

左右キーでスキンを選び、Enterで確定。難易度画面では1=EASY、2=NORMAL、3=HARDで新規開始、Enterで保存済みの続きから再開します。スキンは服を着た7種類です。

## 今回の変更

- 上下の視点操作を反転し、標準ではマウスを上へ動かすと上を向く操作に修正。F10の上下反転設定も使用できます。
- プレイヤーの最大HPは200。区間を進むだけでは回復せず、残りHPを次の区間とセーブデータへ引き継ぎます。
- 敵の弾は発射後に実際に飛び、プレイヤーへ触れたときだけダメージになります。発射後に追尾せず、横移動でかわしたり建物などで遮ったりできます。
- キャラクターに付いていた四角い仮衣装や円形の仮帽子を撤去。既存の服付きキャラクターモデルを使用します。学友会の衣服は黄色、学生会は紺、教授は白を基調とします。
- 各区間に緑の十字付きの回復キットを配置。近くでEを押すと35回復し、最大200を超えません。満タンなら消費しません。一度使ったキットは、その区間の再読み込みで復活しません。
- F2の回復能力は20回復、再使用まで18秒。他のコース能力は再使用まで8秒です。
- 全20区間をクリアすると中央にCLEAR、死亡するとGAME OVERを表示します。

## 操作

|操作|キー|
|---|---|
|移動と視点|WASDとマウス|
|射撃と照準|左クリックと右クリック長押し|
|リロード|R|
|武器選択|1〜3 またはマウスホイール|
|ダッシュ|前進しながら左Shift|
|しゃがむと立つ|左Ctrl|
|スライディング|高速ダッシュ中に左Ctrl|
|ジャンプ|Space|
|武器と回復キットを拾う|近くでE。近い方の対象を使用|
|持ち物と作成強化|Tabで開き、1〜3で対象を選び、Fで作成・強化|
|コースと特殊能力|F1〜F4で選び、Gで使用|
|設定と一時停止|F10。上下で項目選択、左右で変更、F10で保存して復帰|
|保存して終了|Esc|

持ち物を開いている間も敵は動きます。休止するときはF10を使ってください。

## クリアとリスタート

各区間では護衛2体を倒すと教授が出現します。教授を倒して道沿いに次の番号へ進み、全20体の教授を倒すとクリアです。

GAME OVERではEnterで同じ区間から再挑戦します。再挑戦時はHP200で始まります。これは区間を通常通過するときのHP引き継ぎとは別です。Rを押すと装備・強化・部品をリセットして最初からやり直します。

CLEARではEnterまたはRで最初から新しいプレイを始めます。いずれの終了画面でもEscで終了できます。

## 素材と動作環境

64bit WindowsとDirectX 12対応のグラフィックス環境を使用します。別PCでの動作は未検証です。

太一モデルはGame Asset StudioのTaichi Character Pack、Manny・Quinn、射撃・移動動作およびライフルはUnreal Engine標準素材を使用しています。校舎は中百舌鳥キャンパスをモチーフにした近似表現です。登場人物はゲーム上の架空のキャラクターで、大学等の公式作品ではありません。

以前のWordマニュアルにある「区間開始時の全回復」「水着スキン」「F2の全回復」は、本改善版では変更されています。本版の操作はこの説明を参照してください。

## 2026年11月6日 走行修正

移動中に足が固定される問題を修正しました。歩行・走行・ダッシュ・横移動で足が交互に動きます。射撃・リロードは上半身へ適用し、移動中の脚の動作を維持します。操作キーは従来どおりです。
